# Frontend Initial Requirements (Archived)

This file captures the original build specification for the frontend. Current guidance lives in:
- .aiassistant/rules/20_FRONTEND_RULES.md
- .aiassistant/rules/21_FRONTEND_WORKFLOW.md

Original requirements summary:
- React + TypeScript + Vite
- Tailwind CSS + typography plugin
- TipTap editor
- Zustand for state management
- Central API client with tolerant parsing
- Auth, document list, editor, autosave, history, import/export, search
- LocalStorage fallback when commits are not supported
